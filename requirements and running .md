## Requriements:

 - python
 - websockets
 - cyrptography

## how to run program 

step-1 open terminal and create a virtual envirnoment 

```
python -m venv myenv
```
myenv here is the naming of the virtual environment file

step-2 activate that virtual environment 

```
source myenv/bin/activate
```

step-3 install the requirements of this project 

```
pip install websockets cryptography
```

step-4 change the dirctory, target the  project file 

```
cd "/home/unix/E2EE messenger"
```
path here can be different according to the system of computer 

step-5 start the server 

```
python server.py
```

step-6 start new window of terminal and activate virtual envirnoment in it , don't create another virtual env , just actiavte the existing virtual env....with similar syntax as before

step-7 change directory to the project directory same as done in server's window terminal ...


step-8 start client 

```
python client.py
```

step-9 open two or more terminals and start client in it for better demonstration of the project
